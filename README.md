# Món quà 19/11 – Gửi anh

## Chạy thử bằng VS Code
1. Giải nén thư mục.
2. Mở VS Code → File → Open Folder → chọn thư mục `mon_qua_19_11`.
3. Mở `index.html`.
4. Nếu có tiện ích **Live Server**: nhấn chuột phải `index.html` → **Open with Live Server**.
   Nếu chưa có, có thể mở trực tiếp `index.html` bằng trình duyệt để xem bản cơ bản.

## Đưa lên mạng để tạo QR
QR cần một đường dẫn công khai (https://...). Địa chỉ localhost hoặc đường dẫn Live Server chỉ chạy trên máy của bạn, người nhận quét bằng điện thoại sẽ không mở được.

Cách miễn phí bằng GitHub Pages:
1. Tạo tài khoản/đăng nhập GitHub.
2. Tạo repository mới, ví dụ `mon-qua-19-11`.
3. Tải lên 3 tệp `index.html`, `style.css`, `script.js`.
4. Vào **Settings → Pages**.
5. Ở **Build and deployment**, chọn **Deploy from a branch**, branch `main`, folder `/ (root)`, rồi Save.
6. Chờ GitHub cấp địa chỉ dạng `https://ten-github.github.io/mon-qua-19-11/`.
7. Gửi đường dẫn đó cho mình; mình sẽ tạo mã QR dẫn thẳng đến trang web.

Lưu ý: Đừng gửi QR trước khi trang đã được xuất bản và mở thử bằng điện thoại ở chế độ 4G/5G.
